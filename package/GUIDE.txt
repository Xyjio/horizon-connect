=====================================================================
  HORIZON CONNECT 1.0  -  Forza Horizon 2 online with your friends
=====================================================================

Horizon Connect lets you drive together in Forza Horizon 2's online
free roam - without the Microsoft servers that were shut down. One of
you hosts a server, the others join. Everything needed (the server
and the internet tunnel through playit.gg) is inside the mod; you
don't have to install anything else.


---------------------------------------------------------------------
 1. WHAT YOU NEED
---------------------------------------------------------------------

  - Forza Horizon 2 (Xbox One, version 1.0.0.64) that you own,
    running in Azimuth 1.0.4 on your PC
  - Extra Options 0.4.4 (the mod loader for Azimuth) installed
  - Windows 10 or 11, an internet connection

  If the game already runs with Extra Options for you, you're set.


---------------------------------------------------------------------
 2. INSTALL
---------------------------------------------------------------------

  0. To be safe, back up your save first: copy the folder
         <Azimuth folder>\data\titles\1A96545B\saves
     somewhere else.

  1. Unpack this ZIP.

  2. Copy the folder "Horizon Connect" into Azimuth's mods folder:
         <Azimuth folder>\mods\Horizon Connect\
     The file "mod.json" and the folder "plugins" must be directly
     inside it.

  3. Check your player name. It is the name next to the round profile
     icon at the top right of Azimuth's start window. The others see
     exactly this name above your car.
     - Everyone in your group should have a different name.
     - Don't use a hyphen (-), or the game shows "Player 1" instead
       of your name.
     For a name used only by Horizon Connect: in the file
     mods\Horizon Connect\plugins\HorizonConnect.ini enter it after
     "Gamertag=" (e.g. Gamertag=Max123).

  4. Start Forza Horizon 2.
     If Windows Firewall asks about "python" or "playitd", click
     "Allow".

  At the first start you get your own player id automatically. Your
  save so far is copied for it, so you keep your progress.


---------------------------------------------------------------------
 3. OPEN THE MENU
---------------------------------------------------------------------

  In free roam, open the pause menu and then
      press F12   (controller: the View button)

  "HORIZON CONNECT" opens with your server list.

  Controls in the menu:
      A  do it (e.g. join)                  B  back
      X  edit a server                      Y  delete a server (press twice)
      Up/Down  choose a row

  If you play with the keyboard through the Azimuth Mapper, its keys
  apply. By default:
      A = Space or Enter          B = E or Backspace
      X = Q                       Y = R
      Up/Down = arrow keys

  Important for the Azimuth Mapper: its F6 key switches its mouse
  pointer mode, in which W and S no longer accelerate or brake. If
  gas and reverse stop working, press F6 once (outside the menu).
  That's why Horizon Connect uses F12. You can set another key in
  mods\Horizon Connect\plugins\HorizonConnect.ini under [menu] Key=
  (not F5 to F9: those belong to the Mapper).


---------------------------------------------------------------------
 4. JOIN A FRIEND
---------------------------------------------------------------------

  1. Ask the host for their address (e.g. on Discord).
     It looks like this:   name-something.tun.ply.gg:12345

  2. Copy the address (select it, Ctrl+C).

  3. In the game: pause menu -> F12 -> "Add server" -> A
     The address you copied is already filled in. Choose "Save".
     (If it isn't: go to "Address" and press A.)

  4. The server is now at the top of your list. On the right you see
     whether it can be reached, e.g. "online - 2 players".

  5. Choose the server -> A. The game looks for the session.
     When "FREE ROAM SESSION FOUND - press X" shows at the top:
     press X! (You have 20 seconds.)

  Next time it's just: pause menu -> F12 -> A -> X.


---------------------------------------------------------------------
 5. HOST YOURSELF
---------------------------------------------------------------------

  The very first time (once):
  1. Pause menu -> F12 -> "Host a server" -> "Set up hosting" -> A
  2. Your browser opens playit.gg (free; it is the service through
     which your friends reach you over the internet).
     Log in or create an account and confirm.
  3. Alt+Tab back to the game. After a few seconds the page shows
     "Start the server and join" and your address.

  Every time:
  1. Pause menu -> F12 -> "Host a server"
  2. "Start the server and join" -> A, then press X at
     "FREE ROAM SESSION FOUND".
  3. "Address for friends" -> A copies it. Send it to your friends
     (Ctrl+V). The address always stays the same, so your friends
     only have to add it once.
  4. When you're done: "Stop the server" -> A, or just close the
     game.

  Your game has to keep running while you host.


---------------------------------------------------------------------
 6. TROUBLESHOOTING
---------------------------------------------------------------------

  "can't be reached" in the list
      The host hasn't started their server, or you have different
      versions of Horizon Connect. Everyone should have the newest
      version: when one is out, the server list shows it at the top.
      A installs it, A again restarts the game.

  "Agent deleted" when hosting
      Your playit agent was deleted on playit.gg. "Set up a new one"
      -> A, then confirm in the browser. You get a new address: send
      it to your friends. (A free playit account has room for one
      agent.)

  Nothing happens after A / the search takes forever
      Pause menu -> F12 -> try again. If that doesn't help, restart
      the game.

  Started an event (race) online and the menu is stuck
      Events don't work in online free roam yet. Restart the game.

  F12 does nothing
      F12 only works in free roam's pause menu (not in races, not in
      the Autoshow, etc.).

  The browser doesn't open when hosting
      Check whether a window opened behind the game (Alt+Tab).

  Gas and reverse don't work (Azimuth Mapper)
      Press F6 once to leave the Mapper's mouse pointer mode.

  Reporting a problem
      Send the person who gave you the mod the file
          <Azimuth folder>\mods\Horizon Connect\plugins\HorizonConnect.log
      (it is written anew at every start).


---------------------------------------------------------------------
 7. WHAT DOESN'T WORK (YET)
---------------------------------------------------------------------

  - Up to 11 players per server.
  - At the moment every player has the crown (session leader).
  - You see the other players' liveries only once they were saved
    online in the paint shop.
  - Collisions between players aren't sent yet.
  - Joining from the list starts free roam on the mainland (not on
    Storm Island).

  What's being worked on: ROADMAP.md on GitHub.


---------------------------------------------------------------------
 8. UNINSTALL
---------------------------------------------------------------------

  Delete the folder  <Azimuth folder>\mods\Horizon Connect
  Your original save is unchanged.

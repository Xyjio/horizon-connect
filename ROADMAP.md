# Roadmap – work in progress

What Horizon Connect can do, what is being worked on, and what comes next.

Found a bug or have a wish? Open an [issue](../../issues).

**Legend:** 🚧 in progress · 📋 planned · 💡 idea (maybe) · ✅ done

## 📋 Planned

- **Join without pressing X** – skip the *"Free roam session found – press X"* prompt.
- **Storm Island** – join the online free roam on Storm Island, not only on the mainland.
- **Traffic in online free roam** – the online free roam has no traffic cars yet (it came from Turn 10's
  servers).
- **Liveries** – see the other players' liveries right away, without saving them online in the paint shop first.

## 💡 Ideas

- Online events and road trips together (racing each other).
- Player list for the host in the HORIZON CONNECT menu (who is connected).

## ✅ Done

### 1.0.5
- Fix for players being disconnected again and again.

### 1.0.4
- Update and restart from the server list with one button.
- The host page notices a deleted playit agent and sets up a new one.

### 1.0.3
- Same weather and time of day for everyone.
- The relay passes on all of the game's messages for other players (e.g. glass, parts coming off).
- A message in the server list when a new version is out.

### 1.0.2
- One session leader (star icon): the host, or whoever has been in the session longest; passed on when they leave.
- Collisions and repairs between players.

### 1.0.1
- In-game server list in the pause menu: add, edit, delete, status and player count of each server.
- Hosting over the internet with the built-in playit.gg agent (set up once, then start with one button).
- Joining starts the game's own *Private Free Roam Online*.
- Every player gets their own player id automatically; the save so far is copied for it.
- German and English menu texts.

See also the [changelog](CHANGELOG.md).
